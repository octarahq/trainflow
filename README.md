## About

`TrainFlow` is an independent real-time tracking and visualization platform for the French national rail network. By leveraging **SNCF** Open Data feeds, the application allows users to monitor train positions, view live delays, and analyze global traffic performance statistics.

You can access the service online at [trainflow.octara.xyz](https://trainflow.octara.xyz) or check the developer documentation at `https://trainflow.octara.xyz/developers` (coming soon).

> For an optimal experience, use the interactive map view to locate any train currently operating in France.

## Features

- **Interactive Map**: Visualize all trains moving on the SNCF network in a single fluid interface.
- **Network Statistics**: Access global traffic performance: punctuality rates by line, station, and train type.
- **Traffic Alerts**: Receive information about incidents and delays affecting major lines. (coming soon)
- **Developer API**: A suite of APIs for developers wishing to integrate real-time rail data into their own applications. (coming soon)

## Installation

Node.js 22 or newer is required. The application is built with **Next.js 16** and **TypeScript**.

```sh
# Install dependencies
npm install

# Start the development environment
npm run dev

# Build for production
npm run build
npm start
```
